# Athul Krishna R — Developer Portfolio

> **Full Stack & AI Systems Developer • MCA Student @ MEA Engineering College**  
> Clean, minimalist Apple-inspired developer portfolio hosted natively on GitHub Pages at [athul3588krishna.github.io](https://athul3588krishna.github.io/).

---

## ✨ Features

- **Apple / iOS Design System:** Pure Vanilla CSS with fluid typography, frosted glass header, squircle cards, and smooth micro-interactions.
- **Dual Visual Theme:** High-contrast OLED dark mode + soothing slate light mode with `localStorage` memory and system preference detection.
- **Pure Static Architecture:** Zero build steps, zero npm dependencies, zero complex CI/CD. Deploys directly from the `main` branch via GitHub Pages.
- **Interactive Lightboxes & Modals:**
  - Full technical case studies for flagship projects (Problem, Solution, Architecture, Contributions).
  - High-resolution SVG credential certificates with official verification links.
- **Fully Responsive:** Optimized for smartphones, tablets, and desktop displays with dedicated touch-friendly drawers and floating navigation.
- **ATS Resume Download & Direct Contact:** Click-to-copy email and validated messaging.

## 🚀 Local Preview

Open `index.html` directly in any web browser, or serve locally with any static file server:

```bash
# Python 3
python -m http.server 3000

# or Node.js npx
npx serve .
```

Visit `http://localhost:3000` to view the portfolio.
